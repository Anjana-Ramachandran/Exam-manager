## <span style="color:coral;">Features</span>

### Administrator:
- **Create Exam Details**: Admins can create and manage exam details, including date, time, and location.

### Students:
- **View Exam Details**: Students can create accounts and log in to view their upcoming exams, including subject, date, time, and location.

### Invigilators:
- **Mark Attendance**: Invigilators can mark attendance for students during the exam.

## <span style="color:mediumseagreen;">Technology Stack</span>

- **MongoDB**: Database to store exam details, user information, and attendance records.
- **Express.js**: Web framework for building the backend APIs.
- **Angular**: Frontend framework for building the user interface.
- **Node.js**: Server environment for running the application.

## <span style="color:royalblue;">Goals</span>

- **Efficiency**: Simplify exam management for educational institutions.
- **User Experience**: Provide a seamless experience for students and invigilators.
- **Security**: Ensure data privacy and secure access to exam details and attendance records.
